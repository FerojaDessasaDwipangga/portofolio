### 👨‍💻 About Me

Saya memiliki latar belakang di bidang Instalasi Tenaga Listrik dengan pengalaman operasional yang kuat di bidang pergudangan dan *Production Planning and Inventory Control* (PPIC). Saat ini, saya fokus membangun alat digital yang dapat memecahkan masalah nyata di lantai produksi, mulai dari otomasi pelaporan hingga pemantauan inventaris secara *real-time*.

- 🔭 **Currently working on:** Mendigitalisasi pemantauan *Work In Progress* (WIP) dan pelacakan proses produksi U-bolt (termasuk *HOT Bending* dan *machine trials*).
- 🌱 **Currently learning:** Memperdalam *framework* modern untuk membangun antarmuka web industri yang lebih responsif.
- 🎯 **Goals:** Mengambil sertifikasi resmi di bidang teknologi untuk terus meningkatkan nilai profesional.
- ⚡ **Fun fact:** Jika sedang tidak merumuskan logika aplikasi atau menganalisis data produksi, saya biasanya sedang berlatih lari di jalanan. Sedang mengejar target *finish Half-Marathon* di bawah 2 jam dengan *pace* 7.10! 🏃‍♂️💨
